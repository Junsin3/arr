\section{서론}

웹 그래픽 사용자 인터페이스(GUI)를 조작하려면 화면에 밀집된
텍스트를 읽는 능력, 요소의 기능과 현재 상태를 이해하는 능력, 그리고
언어로 지시된 대상을 화면 좌표에 연결하는 능력이 함께 필요하다.
VisualWebBench의 세부 분석은 범용 멀티모달 모델이 특히
텍스트가 많은 웹 화면의 그라운딩과 저해상도 입력에서 어려움을
겪는다는 사실을 보여준다 \citep{liu2024visualwebbench}. 이에 최근
연구는 DOM을 직접 입력하지 않고 스크린샷에서 행동을 예측하는
native GUI agent를 구축하면서, 행동 궤적 이전 또는 그와 함께
화면 설명과 요소 그라운딩을 학습한다
\citep{qin2025uitars,gupta2026molmoweb}. 웹 UI로 만든 대규모
명령어 데이터가 웹 이해뿐 아니라 문서와 차트 이해에도 전이된다는
결과 역시 웹 화면이 텍스트 밀집 시각 표현을 학습하는 유용한
원천임을 뒷받침한다 \citep{liu2025multiui}.

이러한 모델의 학습 레시피를 비교하는 과정에서 우리는 공통적인
구조와 통제되지 않은 선택을 함께 관찰하였다. 많은 레시피가
지각 supervision을 먼저 제공하고 이후 명령어 또는 행동 데이터를
학습하지만 \citep{qin2025uitars,gupta2026molmoweb}, 지각 단계에서
한 화면을 얼마나 자세히 언어화하는지는 데이터 혼합과 함께
달라진다. 따라서 기존 결과만으로는 자세한 화면 설명이 후속 웹
에이전트 학습에 필요한 기반을 제공하는지, 아니면 핵심 정보만
남기는 짧은 설명으로 충분한지 판단하기 어렵다. 범용
시각언어모델에서도 초기 이미지--텍스트 정렬과 후속 명령어 튜닝을
구분하는 학습 방식이 널리 사용된다는 점
\citep{liu2023llava,liu2024llavanext}은 이 초기 supervision의
역할을 별도로 측정할 필요성을 제기한다.

이 관찰로부터 우리는 설명의 상세도가 웹 GUI 표현에 남기는 효과와
그 효과의 지속성에 주목한다. 짧은 설명은 페이지의 목적, 핵심 상태,
대표 상호작용에 학습 신호를 집중한다. 긴 설명은 작은 텍스트, 표의
항목, 상태, 행동 가능한 요소까지 보존하므로 더 풍부한 표현을
형성할 가능성이 있다. 반면 장문은 중요도가 낮은 사실을 과도하게
나열할 수 있으며, 초기 차이가 후속 명령어 튜닝과 행동 궤적
학습에서 소거될 수도 있다. 즉, ``더 자세한 설명이 더 낫다''는
가정은 PT 직후 성능뿐 아니라 후속 학습 이후까지 추적해야 검증할
수 있다. 그림 \ref{fig:contrast}는 이 비교와 통제 변수를 요약한다.

이를 위해 동일한 스크린샷과 Stage 1 구조화 사실로부터
\textbf{간결한 설명(Short)}과 \textbf{포괄적 설명(Long)}을
생성한다. 두 조건은 좌표 규약, 외부 그라운딩 데이터, 기반 모델,
최적화 설정, 후속 데이터를 공유하며, Stage 2에서 어떤 정보를
얼마나 남겨 서술하는지만 다르다. 효과는 PT 직후, 공통 IT 직후,
Trajectory SFT 직후의 세 지점에서 측정한다. 이 설계는 Long
supervision이 웹 이해를 개선하는지뿐 아니라, 그 차이가 과제특화
학습 이후 최종 에이전트까지 이어지는지를 구분한다.

본 연구의 기여는 다음과 같다.
\begin{itemize}
    \item 그라운딩 양과 후속 데이터를 고정한 상태에서 웹 GUI
    사전학습의 서술 상세도를 비교하는 통제 실험을 설계한다.
    \item 아홉 개 체크포인트를 통해 PT의 효과가 어느 단계에서
    나타나고 후속 학습 이후까지 유지되는지 추적한다.
    \item 접근성 트리의 bounding box 좌표를 teacher가 추정하지 않고
    인용하도록 하며, 프로그램 검증으로 좌표 발명을 제거하는 2단계
    합성 파이프라인을 제시한다.
\end{itemize}
현재 최종 평가가 진행 중이므로 어느 조건의 우월성을 전제하지
않는다. 대신 측정된 합성 데이터 품질과 단계별 비교를 함께
제시하여, 최종 결과가 서술 상세도의 즉시 효과와 지속 효과를
분리해 해석할 수 있도록 한다.
