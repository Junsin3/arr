\section{서론}

웹 그래픽 사용자 인터페이스(GUI)를 조작하려면 화면의 밀집된
텍스트를 읽고, 요소의 기능과 상태를 이해하며, 언어로 지시된
대상을 정확한 위치에 연결해야 한다. 웹 질의응답에서도 텍스트
의미만으로는 충분하지 않고 페이지 구조가 필요하며
\citep{chen2021websrc}, VisualWebBench는 현재 멀티모달 모델이
텍스트가 많은 웹 화면의 이해와 그라운딩에서 여전히 어려움을
겪음을 보여준다 \citep{liu2024visualwebbench}.

최근의 native GUI agent는 DOM이나 접근성 트리를 추론 시점의
입력으로 사용하지 않고 스크린샷에서 직접 행동을 예측한다. 이를
위해 화면 이해와 요소 그라운딩을 먼저 학습한 뒤 행동 궤적으로
적응하거나, 이 데이터를 하나의 학습 mixture에 결합한다
\citep{cheng2024seeclick,qin2025uitars,gupta2026molmoweb}. 그러나
각 연구의 화면 supervision은 element description, screenshot QA,
dense caption처럼 서로 다르고, 데이터 규모와 후속 학습도 함께
변한다. 따라서 기존 결과만으로는 초기 화면 설명을 얼마나 자세히
해야 하는지 판단하기 어렵다.

우리는 이 문제를 실제 학습 데이터를 구축하는 과정에서 관찰했다.
짧은 caption은 페이지의 목적과 핵심 상태에 신호를 집중하지만,
작은 텍스트와 주변 요소의 관계를 생략한다. 반대로 긴 description은
가시 텍스트, 상태, 요소의 기능과 예상 상호작용 결과를 폭넓게
보존하지만, 중요도가 낮거나 이미지에서 확실히 확인하기 어려운
내용까지 학습시킬 수 있다. 자연 이미지에서도 caption의
image alignment와 속성ㆍ관계ㆍ상태의 coverage가 compositional
representation에 영향을 주지만 \citep{doveh2023dac}, 길이 자체가
정보 specificity를 보장하지는 않는다
\citep{kapur2026morewords}. 따라서 본 연구의 질문은 단순히
``긴 문장이 더 좋은가''가 아니라, \emph{동일한 웹 화면의 사실을
더 포괄적으로 언어화한 supervision이 어떤 능력을 만들고 그 효과가
후속 agent 학습까지 유지되는가}이다.

이를 검증하기 위해 동일한 스크린샷과 구조화된 화면 사실에서
\textbf{간결한 설명(Short)}과 \textbf{포괄적 설명(Long)}을
생성한다. 좌표 규약, 외부 그라운딩 데이터, 기반 모델과 후속
데이터를 통제하고, 설명에 보존되는 정보의 범위만 다르게 한다.
PT 직후에는 웹 이해와 그라운딩을 분리해 측정하고, 이후 동일한
IT, Action, Trajectory 학습을 거치며 차이가 유지되는지 추적한다.
또한 Long에서 요소 상세, 기능ㆍaffordance, 예상 화면 변화를
제거하는 분석으로 관찰된 차이가 어느 정보에서 비롯되는지
확인한다.

실제 준비된 대규모 recipe에는 영어 Short PT와 영어ㆍ한국어 Long
PT가 포함되어 있어 언어와 데이터 규모가 완전히 일치하지 않는다.
따라서 이 비교는 실제 recipe의 효용으로 보고하고, description
상세도의 인과 효과는 화면ㆍ언어ㆍ그라운딩ㆍ후속 sample을 맞춘
Short/Long subset에서 별도로 판단한다. 현재 최종 모델 평가가 진행
중이므로 어느 조건의 우월성도 전제하지 않는다.

본 연구의 기여는 다음과 같다.
\begin{itemize}
    \item 동일한 웹 화면 사실에서 생성한 Short/Long supervision을
    비교하여 설명의 상세도와 데이터 규모ㆍ그라운딩 양을 분리하는
    실험 설계를 제시한다.
    \item PT, IT, Action, Trajectory checkpoint를 평가하여 초기
    화면 supervision의 즉시 효과와 최종 agent까지의 지속 효과를
    구분한다.
    \item 접근성 트리에서 얻은 좌표를 teacher가 인용하게 하고
    프로그램 검증으로 좌표 발명을 제거하는 2단계 데이터 합성
    절차를 제시한다.
\end{itemize}
